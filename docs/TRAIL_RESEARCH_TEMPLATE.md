| measure-1 | | | seizure / production / stock / flow / shipment / capacity / value / case count | unknown | | | | |

State uncertainty and comparability. Unknown becomes `null` in machine-readable data. Preserve original units and any conversion method. Do not turn seizures into total trafficking, stocks into annual movement, capacity into actual use, or national totals into corridor totals. Record double-counting risks. A shared country pair does not justify a shared quantity across substances.
